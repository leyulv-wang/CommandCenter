# 最小化 CommandCenter 测试台设计

## 目标

将旧项目遗留的多页面前端替换为一个最小化单页测试台，只服务当前已经确定的产品闭环：

```text
浏览器演示 → API Skill → 中控执行
```

页面面向当前项目开发者和测试人员，用于确认浏览器扩展录制是否被中控接收、智能体是否生成
API Skill，以及自然语言任务是否能够进入中控执行流程。它不是管理员配置平台，也不是业务
表单门户。

## 范围

### 保留

1. 自然语言任务输入。
2. 任务执行状态、错误和最终结果。
3. 最新浏览器扩展录制的学习结果。
4. 最近录制列表。
5. 自动刷新分析中的录制，以及手动刷新。

### 删除

1. 侧边栏和页面切换。
2. 配置化表单和动态表单入口。
3. 外部业务系统配置页面。
4. AI 表单配置页面。
5. 普通待办、已完成任务和双用户测试界面。
6. 旧的中控内嵌演示窗口及四阶段发布流程。

删除仅限正式 Vue 前端。后端兼容接口、本地测试业务系统和浏览器扩展不在本次改动范围内。

## 单页信息架构

页面从上到下由四个部分组成：

1. 顶栏：产品名称、页面用途和中控服务状态。
2. 路径说明：固定展示“浏览器演示 → API Skill → 中控执行”，解释当前闭环。
3. 核心工作区：左侧自然语言执行，右侧最新学习结果。
4. 最近录制：展示最近浏览器扩展录制及其终态或处理中状态。

桌面端核心工作区使用双列布局，窄屏和移动端改为上下排列。

## 自然语言执行区

执行区复用现有 `/task-runs` API：

1. 用户输入一项自然语言业务任务。
2. 点击“执行任务”后展示中控返回的真实状态。
3. 当后端要求选择业务对象时，展示候选对象供用户选择。
4. 成功时展示摘要和输出；失败时展示后端错误。

前端不根据关键词判断 Skill，不伪造成功，也不因为最新录制处于 `api_candidate` 就自行决定
任务能否执行。Skill 选择、权限和执行连接状态仍由后端负责。

## 最新学习结果区

页面读取最近一条 `capture_source=browser_extension` 的录制，并展示：

- 演示目标；
- 来源系统；
- 当前状态；
- 更新时间；
- 候选 Skill 名称；
- 失败原因（如果存在）。

状态文案必须区分：

- `analyzing`：智能体正在分析；
- `api_candidate`：API Skill 已生成，等待业务系统执行连接；
- `verified_candidate`：Skill 已完成验证；
- 上传、分析或测试失败：显示真实失败原因和重试方向。

`api_candidate` 不是失败、发布成功或员工可执行状态，页面不得混淆这三个概念。

## 最近录制区

最近录制采用紧凑列表，不增加筛选、分页和编辑操作。每行显示目标、来源系统、状态和更新
时间。点击一行后可将其作为右侧学习结果查看；默认选择最新一条。

列表的作用是区分真实 MES 录制与本地测试系统录制，并帮助定位最新一次测试，不承担录制
管理功能。

## 刷新与错误处理

1. 页面首次加载时读取录制列表。
2. 最新录制处于处理中状态时定时刷新。
3. 录制进入终态后停止自动刷新。
4. 用户可以随时手动刷新。
5. 中控不可用时，顶栏显示离线，内容区保留上一次结果并给出明确连接错误。
6. 空列表提示用户先通过浏览器扩展完成一次录制。

自动刷新只是状态同步机制，不参与任何业务判断。

## 视觉方向

页面采用简洁的企业控制台视觉，不复用旧表单平台样式：

- 背景 `#F3F6F8`（雾灰）；
- 主文字 `#15232E`（墨蓝）；
- 运行信号 `#0E8A9D`（青蓝）；
- 成功 `#198754`（绿色）；
- 等待连接 `#C67A16`（琥珀色）；
- 边界 `#D8E1E7`（浅灰蓝）。

中文正文使用系统无衬线字体，录制编号、状态和时间使用等宽字体。唯一强调性视觉是路径说明
“浏览器演示 → API Skill → 中控执行”，其余区域保持克制。动画仅用于处理中状态，并遵循
`prefers-reduced-motion`。

## 组件边界

前端拆分为三个单一职责组件：

1. `TaskCommandPanel`：自然语言输入和任务执行结果。
2. `LatestLearningResult`：单条录制与候选 Skill 详情。
3. `RecordingHistory`：最近录制列表和选择事件。

页面容器负责加载数据、轮询和选择状态；组件不直接互相调用，也不承载后端业务判断。

## 测试与验收

自动测试覆盖：

1. 页面不再出现旧的四个导航入口。
2. 自然语言任务能够提交并展示成功、失败或对象选择状态。
3. `api_candidate` 显示“API Skill 已生成，等待执行连接”。
4. 最近录制能够切换当前详情。
5. 分析中自动刷新，终态停止刷新。
6. 后端不可用、空数据和失败原因有明确提示。
7. 桌面和窄屏布局不溢出。

实施完成后运行前端单元测试和生产构建，并通过本地中控数据现场确认最新真实 MES 录制能
正确显示。验收不要求真实调用 MES；真实执行仍依赖后续安全执行连接。
