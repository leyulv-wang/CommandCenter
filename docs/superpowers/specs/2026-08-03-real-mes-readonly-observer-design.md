# CommandCenter 真实 MES 只读观察器设计

状态：已实施，待真实只读验收（首次验收因浏览器禁止自动进入扩展管理页而未完成）

日期：2026-08-03

适用范围：`D:\python\CommandCenter`

## 1. 背景

CommandCenter 已在本地采购测试系统中实现“员工演示一次、智能体学习 API Skill、自动测试、自然语言调用”的单系统闭环。现有录制器通过 Playwright 启动独立 Chromium，并只识别本地测试系统的固定端口，因此还不能观察员工已经登录的真实业务系统标签页。

本阶段接入江苏益丰新材料数字化管控系统进行技术验证。该 MES 是 Jeecg-Boot 系统，提供 Swagger 2.0 接口文档，API 使用 `X-Access-Token` 请求头鉴权。接口文档中部分改变业务状态的接口也使用 GET，例如审核、完成和反审核，因此不能把 HTTP 方法作为只读安全性的唯一依据。

本设计只涉及读取和观察，不保存、修改、审核、完成或删除 MES 中的业务数据。

## 2. 目标

本阶段验证以下最小闭环：

> 员工在已经登录的 MES 标签页中演示一次采购申请查询，中控同时记录页面控件和网络请求，由智能体建立字段与 API 的对应关系，生成并验证一个只读的“查询采购申请”候选 Skill。

第一版采用：

```text
通用浏览器录制扩展
＋ MES 系统配置
＋ 智能体轨迹分析
＋ API Skill 生成
```

浏览器扩展保持通用，MES 的域名、接口文档、脱敏规则和只读接口范围通过系统配置提供。后续接入 ERP、WMS、OA 等系统时，应优先增加系统配置和适配器，而不是重新开发专用扩展。

## 3. 非目标

第一版不做：

- 录制或回放桌面程序；
- 录制其他浏览器标签页；
- 通过坐标生成 RPA；
- 自动创建、编辑、审核、完成或删除 MES 数据；
- 真实生产写操作的自动测试；
- 向普通员工发布真实 MES Skill；
- 完整账号、角色和租户权限体系；
- 多次演示融合；
- 无 API 系统的浏览器执行器；
- 正式商店安装包、企业扩展分发和复杂管理后台。

## 4. 总体架构

```text
员工操作指定 MES 标签页
          ↓
通用浏览器录制扩展
├─ 页面控件与用户操作
├─ 局部页面状态变化
├─ 该标签页的网络请求与响应摘要
└─ 本地脱敏与批量上报
          ↓
CommandCenter 观察服务
├─ 录制会话生命周期
├─ 结构化事件时间轴
├─ MES OpenAPI Tool 目录
└─ 本地证据存储
          ↓
多智能体学习流程
├─ 轨迹整理
├─ API 归因
├─ 字段映射
├─ Skill 编译
└─ 安全验证
          ↓
已验证候选 Skill
```

### 4.1 通用浏览器录制扩展

第一版使用 Chromium Manifest V3 扩展，支持 Chrome 和 Edge。用户在扩展弹窗中主动选择“开始录制当前标签页”和“结束录制”。

扩展由两部分组成：

1. 内容脚本：观察页面控件、用户操作和局部页面变化。
2. 扩展后台：只绑定用户选择的标签页，通过浏览器调试协议观察该标签页的网络事件。

扩展不得读取浏览器密码库、浏览历史、其他标签页、Cookie 存储或本地存储。绑定标签页离开允许域名时自动暂停，录制结束后立即解除绑定。

### 4.2 CommandCenter 观察服务

现有 `OperationTrace`、录制会话、证据存储和学习流程继续复用。现有 Playwright 录制器保留用于本地测试系统，真实系统新增扩展事件接入方式。二者最终产生统一的操作轨迹，避免让录制来源影响内部 Skill 表示。

观察服务负责：

- 创建和结束录制会话；
- 接收扩展分批上传的事件；
- 校验会话、系统、域名和事件协议；
- 对事件排序、去重和限流；
- 保存脱敏后的结构化证据；
- 加载真实系统的 OpenAPI Tool 目录；
- 把完整轨迹交给学习智能体。

### 4.3 MES 系统配置

MES 配置至少描述：

- 系统标识和显示名称；
- 允许域名 `yifeng.dtsum.com`；
- OpenAPI 文档地址 `/jeecg-boot/v2/api-docs`；
- API 路径前缀 `/jeecg-boot/`；
- 请求和响应脱敏规则；
- 允许作为只读 Tool 的明确 operationId 或接口路径；
- 当前运行模式为只读观察；
- 凭据引用方式。

Token 不写入配置文件、录制轨迹、提示词、Skill 或日志。执行层在实际请求发送前通过受控凭据引用注入 Token。

## 5. 录制内容

### 5.1 页面控件事件

观察器记录：

- 控件类型、角色和可访问名称；
- 标签、占位文字和必要的稳定属性；
- 所属表单、弹窗、区域、表格列和表格行；
- 点击、输入、选择、提交和焦点完成事件；
- 输入前后的业务值或脱敏指纹；
- 下拉框显示值和实际业务编码之间的关系；
- 事件时间、页面地址和录制会话。

不记录每次鼠标移动和每个键盘按键。密码框的值始终丢弃。

### 5.2 页面状态变化

观察器只保存与业务结果有关的局部证据：

- 弹窗打开或关闭；
- 成功、失败和校验提示；
- 列表刷新和必要的行级变化；
- 页面出现的业务编号；
- 操作前后的局部控件状态。

第一版不默认保存整页截图。只有结构化证据不足时才允许保存经过脱敏的局部截图，并明确关联到具体事件。

### 5.3 网络事件

观察器记录：

- 请求方法、主机、路径和时间；
- 查询参数和请求体的脱敏结构；
- 响应状态、耗时和有限大小的响应摘要；
- 请求的页面来源和相邻 UI 事件；
- OpenAPI 中匹配到的 operationId、标签和数据模型。

响应体设定大小上限。静态资源、心跳、日志上报和与目标无关的请求可以保留最小元数据或直接忽略，但忽略理由必须可追溯。

## 6. 隐私与安全边界

绝对禁止进入轨迹、模型上下文和普通日志的内容包括：

- 密码；
- Cookie；
- `Authorization`；
- `X-Access-Token`；
- 验证码和一次性认证信息；
- 浏览器保存的凭据；
- 上传文件的实际内容；
- 其他标签页内容。

普通测试值可以保存在本地脱敏轨迹中。敏感业务值优先转换为稳定指纹，使智能体能够判断页面值与 API 值是否相同，而不接触完整原值。原始证据只在本机受控范围内短期存在；交给模型的始终是脱敏后的结构化轨迹。

安全代码负责确定性边界：

- 域名和标签页隔离；
- 明确的接口 Tool 白名单；
- 凭据隔离；
- Schema 校验；
- 请求和响应大小限制；
- 超时、限流和资源限制；
- 事件序列、证据引用和审计日志；
- 禁止测试阶段调用任何未明确批准的接口。

## 7. 智能体学习流程

### 7.1 轨迹整理智能体

根据时间轴、页面区域和状态变化，把连续事件整理成业务操作片段，例如“填写查询条件”“点击查询”“打开详情”。时间只用于形成候选关系，不能单独证明因果关系。

### 7.2 API 归因智能体

结合以下证据判断页面动作对应哪些 API：

- UI 与请求的时间关系；
- 页面字段与请求参数的数据关系；
- OpenAPI 接口摘要和参数模型；
- 响应结果与后续页面变化；
- 请求是否属于核心业务、辅助查询、结果验证或无关伴随请求。

一次页面动作可以对应多个 API。智能体必须保留归因证据和无法确定的候选，不得使用“点击后的第一个 POST”之类的硬编码规则替代判断。

### 7.3 字段映射智能体

字段映射覆盖：

- 页面值与 API 值完全相同；
- 日期、数字等格式转换；
- 页面显示名称与后台 ID、编码的转换；
- 数组、主表和明细表结构；
- 系统自动生成字段；
- 用户输入字段和可选字段。

映射结果必须引用页面事件、API 请求、接口文档和必要的响应证据。智能体不能确定时应报告缺少的证据，而不是生成猜测映射。

### 7.4 Skill 编译智能体

第一条候选 Skill 为“查询采购申请”，支持把自然语言查询条件映射到采购申请列表、详情和明细查询 Tool，并返回申请单号、请购信息、物料、数量、需求日期和状态等结构化结果。

生成结果保持系统无关的内部 Skill 表示，不把 MES 的 Swagger Schema 直接作为唯一内部表示，也不把页面坐标或脆弱选择器作为主要业务语义。

### 7.5 安全验证智能体

验证智能体只能使用 MES 配置中明确批准的只读 Tool。第一版允许验证：

- 采购申请分页列表查询；
- 采购申请按 ID 查询；
- 采购申请明细按主表 ID 查询。

GET 方法不自动获得只读资格。审核、完成、反审核等改变状态的 GET 接口必须排除。

验证通过后，Skill 状态为“已验证候选”，不向普通员工自动发布。待真实系统账号、权限和生产写操作隔离方案建立后，再讨论自动发布和写操作 Skill。

## 8. 用户流程

```text
启动 CommandCenter
→ 在浏览器中加载测试版扩展
→ 打开并登录 MES
→ 进入采购申请列表
→ 开始录制当前标签页
→ 输入查询条件并查询
→ 打开一条申请详情
→ 结束录制
→ 中控分析轨迹
→ 生成“查询采购申请”候选 Skill
→ 智能体执行只读验证
→ 展示字段映射、API 归因、证据和验证结果
```

## 9. 异常处理

出现以下情况时停止 Skill 生成或验证，并保存可理解的失败原因：

- 扩展与中控断开；
- 标签页离开允许域名；
- 未捕获到可解释的 API；
- 多个候选 API 无法区分；
- 字段映射证据不足；
- 事件中存在未脱敏凭据；
- 候选接口不在只读 Tool 白名单；
- OpenAPI 文档与真实请求不一致；
- 验证结果与演示结果不一致；
- 浏览器调试通道被其他工具占用。

异常不得通过增加样例专用关键词、固定接口猜测或放宽安全白名单来掩盖。

## 10. 测试策略

### 10.1 本地自动测试

- 控件语义提取；
- 敏感值和请求头脱敏；
- 事件排序、去重和批量接收；
- 标签页和域名隔离；
- OpenAPI Tool 匹配；
- 页面/API 字段映射协议；
- 明确只读 Tool 白名单；
- 未批准 GET 写接口拒绝；
- 断线、超时和超大响应处理；
- 现有本地采购 Skill 闭环回归测试。

### 10.2 真实 MES 只读验证

只执行采购申请列表查询和详情查看。验证：

1. 扩展能够绑定已登录的 MES 标签页；
2. 其他标签页不被观察或控制；
3. 页面控件和对应 API 被记录；
4. 凭据不进入轨迹；
5. 智能体能够区分列表、详情、明细和伴随请求；
6. 页面字段能够映射到 API 参数；
7. 候选 Skill 能通过只读查询验证；
8. MES 中不存在由测试产生的新增、修改或状态变化。

## 11. 完成标准

以下条件全部满足时，测试版完成：

1. 用户可以通过扩展开始和结束当前标签页录制；
2. 录制只作用于 `yifeng.dtsum.com` 的选定标签页；
3. 控件、页面变化和网络请求进入统一时间轴；
4. 密码、Cookie、Token 和验证码被确定性移除；
5. OpenAPI 文档转换成受控 Tool 目录；
6. 智能体生成带证据的操作/API 归因；
7. 智能体生成带证据的字段映射；
8. 生成“查询采购申请”候选 Skill；
9. 候选 Skill 通过明确白名单内的只读验证；
10. 真实 MES 原有业务数据和状态不发生改变；
11. 后端测试、扩展测试和现有前端构建通过。

## 12. 后续演进

只读 API Skill 稳定后，按以下顺序演进：

1. 增加更多真实 MES 只读 Skill；
2. 建立测试账号、测试数据范围和权限隔离；
3. 只允许操作本次测试创建的数据，验证写操作 Skill；
4. 增加 API 与浏览器混合执行；
5. 增加无 API 系统的浏览器执行器；
6. 支持多次演示融合和运行轨迹持续学习；
7. 完善企业扩展分发、账号、租户、审批和审计能力。
