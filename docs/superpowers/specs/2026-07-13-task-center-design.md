# 任务中心第一版 Spec

状态：自动接入扩展已实现

## 1. 目标

把当前“表单提交”升级为统一的“任务中心”，让员工可以发起申请、处理待办并查看已完成记录。

```text
业务系统产生任务
  -> 中控主动读取待办任务
  -> 员工填写处理结果
  -> 中控提交结果到业务系统
  -> 任务变为已完成
```

第一版不做账户系统，使用固定的演示用户。

## 2. 演示系统接口

已接入的演示业务系统提供两个接口：

1. 获取待办任务接口：返回分配给演示用户的待办任务。
2. 提交处理结果接口：接收任务编号和处理结果，并完成该任务。

任务至少包含：

- 任务编号
- 任务标题
- 任务来源系统
- 任务类型
- 任务内容
- 任务状态
- 创建时间

每种任务类型关联一份动态表单配置，用于生成任务处理页面。

## 3. 任务中心

前端将“表单提交”改为“任务中心”。

任务中心使用三个页签。

### 3.1 发起申请

1. 员工先选择已接入的业务系统。
2. 页面展示该系统允许发起的申请表单。
3. 员工填写表单并提交到对应业务系统。
4. 页面只使用业务名称，不展示接口地址、真实接口或模拟接口等技术信息。

### 3.2 待办任务

1. 默认汇总所有已接入业务系统的待办任务，不要求员工先选择系统。
2. 列表标明任务来源系统和当前状态。
3. 任务详情展示业务系统传来的任务内容。
4. 根据任务类型自动生成处理表单。

员工提交成功后，该任务从待办列表中移除，并进入已完成任务。

### 3.3 已完成任务

1. 汇总当前演示用户已经处理的任务。
2. 展示来源系统、原任务内容、处理结果和完成时间。
3. 已完成任务只读，不能重复提交。

## 4. 中控处理流程

1. 中控读取所有已接入系统的待办或已完成任务。
2. 将不同系统返回的任务整理成统一的任务格式。
3. 根据任务类型找到对应的处理表单配置。
4. 员工填写处理结果。
5. LangGraph 工作流校验字段并组装请求数据。
6. 中控调用任务来源系统的结果提交接口。
7. 刷新任务列表，确认任务已经完成。

## 5. 接入配置

第一版为演示系统手动配置以下信息：

- 系统名称
- 该系统允许发起的表单
- 获取待办任务接口地址
- 提交处理结果接口地址
- 任务类型与处理表单的对应关系

后续 AI 快速接入可以扩展为：根据客户提供的任务接口说明，自动生成以上配置。第一版暂不改造 AI 接入模块。

### 5.1 自动接入办公用品演示系统

办公用品演示系统使用以下重复演示流程：

1. 初始状态为待接入，不出现在员工任务中心。
2. 管理员使用 AI 生成并保存办公用品申请配置。
3. 中控根据配置中的接口地址识别办公用品系统。
4. 保存成功后，系统自动变为已接入，并关联新申请表单。
5. 办公用品系统出现在任务中心，可以发起申请、读取待办和提交处理结果。
6. 接入状态在中控重启后仍然保留。

### 5.2 一键完整重置

现有“一键重置快速接入演示”扩展为：

1. 删除 AI 接入时保存的办公用品申请表单。
2. 将办公用品系统恢复为待接入。
3. 清空演示期间产生的申请和任务处理记录。
4. 恢复办公用品系统的预置待办任务。
5. 保留演示所需的内部任务处理表单。

重置后可以再次执行相同的 AI 接入流程，不需要修改系统编码或表单编码。

## 6. 第一版不做

- 登录、账号和权限管理
- 业务系统主动推送任务
- 定时同步和任务缓存
- 领取、转派、退回和审批
- 多人协作和并发处理
- 自然语言查找或处理任务
- AI 自动生成任务处理结果

## 7. 演示数据

已接入采购系统预置少量待办任务，例如：

- 核对采购数量
- 确认采购用途
- 填写处理意见

提交处理结果后，任务状态在该业务系统的 SQLite 数据库中更新为已完成。

## 8. 验收标准

1. 任务中心包含发起申请、待办任务和已完成任务三个页签。
2. 发起申请时可以选择已接入系统及其申请表单，并真实提交到该系统。
3. 打开待办任务可以看到所有已接入系统的待办，并标明来源系统。
4. 点击待办可以查看任务内容和处理表单。
5. 必填字段未填写时不能提交。
6. 提交后，结果真实写入任务来源业务系统。
7. 已完成任务不再出现在待办列表中，但会出现在已完成任务中。
8. 已完成任务可以查看原任务内容、处理结果和完成时间。
9. 任务中心能够汇总多个已接入系统的任务。
10. AI 保存办公用品配置后，该系统自动出现在任务中心。
11. 办公用品系统支持待办查询、结果提交和已完成查询。
12. 一键重置后，办公用品系统恢复为待接入，并可再次完整演示。

## 9. 一句话总结

任务中心让员工在统一入口中向已接入系统发起申请、处理待办任务并查询自己的已办记录。
