# 外部业务系统接入演示 Spec

状态：已实现基础版本。

已实现内容：

1. 已接入采购系统：独立 FastAPI 服务，使用 SQLite 保存历史数据和新提交记录。
2. 待接入办公用品系统：独立 FastAPI 服务，使用 SQLite 保存新提交记录，并提供接口说明。
3. 中控系统可以查看外部系统列表。
4. 中控系统可以读取外部系统提交记录。
5. 中控的“已接入采购申请”会通过真实 HTTP 提交到已接入采购系统。
6. 前端新增“外部业务系统”页面，可以查看旧数据和新提交数据。
7. 旧的客户真实接口样例已删除，避免误提交到客户环境。
8. 前端新增“一键重置快速接入演示”按钮，可清空待接入系统记录并删除已保存的待接入表单配置。

仍需后续增强：

1. 增加一键复制待接入接口说明到 AI 配置页。
2. 根据真实客户 API 再补鉴权、错误格式适配和字段字典。

## 1. 当前目标

当前阶段要把项目从“中控系统内部模拟提交”推进到“真的连接外部业务系统”。

第一版要做两个很小的本地业务系统：

1. 已接入系统：证明中控已经可以正常连接外部系统。
2. 待接入系统：证明一个新系统可以通过 AI 生成配置后快速接入。

这两个系统都是演示和测试用，不做复杂业务。

## 2. 为什么要做两个系统

现在的内部 mock 只能说明：

```text
中控自己可以返回一个模拟成功结果。
```

但它不能很好说明：

```text
中控真的调用了另一个业务系统。
```

所以需要两个独立的本地业务系统。它们都有自己的接口和 SQLite 数据库，中控通过 HTTP 调用它们。

## 3. 两个业务系统

### 3.1 已接入系统

用途：

```text
演示中控已经具备正常接入能力。
```

第一版能力：

1. 系统里预置几条历史单据。
2. 中控可以读取这些旧数据。
3. 中控可以提交一张新单据。
4. 新单据会保存到这个系统自己的 SQLite 数据库。
5. 再次查询时可以看到新提交的数据。

演示流程：

```text
打开中控
  ↓
查看已接入系统的历史数据
  ↓
填写一张新表单
  ↓
提交到已接入系统
  ↓
查看外部系统记录，确认新数据已写入
```

### 3.2 待接入系统

用途：

```text
演示中控可以快速接入一个新系统。
```

第一版能力：

1. 它是一个独立业务系统，有自己的提交接口。
2. 默认不预置到中控表单配置里。
3. 管理员把它的接口说明交给 AI。
4. AI 生成配置草稿。
5. 管理员保存为正式表单。
6. 保存后，中控可以提交数据到这个系统。
7. 新数据会保存到这个系统自己的 SQLite 数据库。

演示流程：

```text
待接入系统提供接口说明
  ↓
AI 生成表单配置草稿
  ↓
管理员确认并保存
  ↓
新表单出现在中控提交页
  ↓
用户填写并提交
  ↓
待接入系统保存记录
```

## 4. 数据库选择

第一版使用 SQLite。

原因：

1. 够轻，不需要额外安装数据库服务。
2. 能真实保存历史数据和新提交记录。
3. 适合演示“外部系统确实收到了数据”。
4. 后续如果需要，可以再换成 MySQL、PostgreSQL 或客户自己的数据库。

## 5. 中控系统需要新增的能力

### 5.1 查看外部系统数据

中控需要提供一个简单入口，能查看已接入系统里的历史数据。

第一版只需要做到：

1. 展示外部系统返回的记录列表。
2. 能看出哪些是预置旧数据，哪些是新提交数据。
3. 不做复杂筛选、分页、权限。

### 5.2 提交到外部系统

中控已有真实 HTTP 提交能力。

本阶段要把它用于两个本地业务系统：

1. 已接入系统：预置配置，直接可用。
2. 待接入系统：通过 AI 生成配置后再启用。

### 5.3 区分表单来源

页面上需要能区分：

```text
已接入系统表单
快速接入测试表单
旧的样例表单
```

第一版可以用标签展示，不做复杂菜单。

## 6. 旧功能如何处理

现有功能不删除。

保留：

1. 动态表单配置。
2. AI 生成配置草稿。
3. 保存配置为正式表单。
4. 真实 HTTP 提交。
5. 内部 mock 提交。
6. 采购、售后、人事等旧样例表单。

但第一版演示重点要从旧样例表单转移到：

```text
已接入系统
待接入系统
```

旧样例表单可以继续保留，暂时不作为主演示入口。

## 7. 第一版不做

本阶段不做：

1. 登录权限系统。
2. 完整审批流。
3. 复杂业务字段。
4. 多数据库支持。
5. 数据同步任务。
6. 员工自然语言找表单。
7. 员工自然语言自动填单。
8. 删除或重构旧样例功能。

## 8. 成功标准

本阶段完成后，需要能演示：

1. 已接入系统有历史数据。
2. 中控可以查看已接入系统的历史数据。
3. 中控可以提交新表单到已接入系统。
4. 已接入系统的 SQLite 中能看到新提交记录。
5. 待接入系统默认不在中控表单列表里。
6. AI 可以根据待接入系统接口说明生成配置草稿。
7. 草稿保存后，新表单出现在中控表单提交页。
8. 中控可以提交数据到待接入系统。
9. 待接入系统的 SQLite 中能看到新提交记录。

## 9. 一句话总结

这一阶段要证明：

```text
中控不仅能自己模拟提交，还能真的连接外部系统；
同时，一个新外部系统也可以通过 AI + 配置快速接入。
```
